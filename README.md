⬡ WebHarvest Pro

A dark-themed Python GUI that scrapes product names, prices, and ratings from e-commerce websites and exports the data to CSV or JSON.


Install & Run
bashpip install requests beautifulsoup4
python webharvest_pro.py


Features

Scrapes book titles, prices & ratings in real time
Live search, filter, and sort the results table
Export to CSV, JSON, or both
Configurable delay to be respectful to servers
Color-coded activity log
